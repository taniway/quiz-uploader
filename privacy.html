Privacy policy

Last updated: 12 October 2026

Who we are

Quiz uploader is an internal tool operated by Taniway, an eenmanszaak (sole proprietorship) registered in the Netherlands (KvK 42177703). Contact: taniway2026@gmail.com.

The tool is used only by Taniway to upload Taniway's own videos to Taniway's own YouTube channels. It has no other users.

YouTube API Services

Quiz uploader uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

  • Google sign-in token. When the channel owner signs in with Google, the tool receives an access token that allows it to upload videos and manage the videos of the chosen YouTube channel.
  • Basic channel information (channel name, handle and ID), read only to confirm that videos go to the correct channel.
  • Our own video content: the video files, titles, descriptions, tags, thumbnails, subtitles and publish times that Taniway created, which the tool sends to YouTube.

The tool does not access, collect or store any data about viewers or other YouTube users, and does not read comments, messages, analytics or any other account data.

How the data is used

Only to upload and schedule Taniway's own videos on Taniway's own channels. The data is not used for advertising, profiling or any other purpose.

Storage and sharing

The sign-in token is stored only on Taniway's own computer, in a local file that is not uploaded or shared. A local record of uploaded video IDs is kept for Taniway's administration. No data is sold, shared with or transferred to any third party. Video content is sent only to YouTube.

This website uses no cookies and no tracking. It is hosted on GitHub Pages; GitHub may log technical data such as IP addresses as described in the GitHub Privacy Statement.

Keeping and deleting data

The token is kept until access is revoked. Access can be revoked at any time on the Google security settings page (Third-party apps with account access), after which the tool can no longer access the channel. Taniway then also deletes the local token file. To ask about or delete any data, email taniway2026@gmail.com.

Google API Services User Data Policy

Quiz uploader's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
